# TUI 输入框选区与替换

输入框支持用 Shift 加方向键、Home 或 End 选择文本。左右移动以完整字素为单位，组合音符与 ZWJ 表情不会拆开；上下移动沿当前输入框的实际折行宽度选择，经过首尾行时不会调出历史输入。已有 Ctrl/Alt 加左右方向键的按词移动也可与 Shift 组合。

选区使用主题已有的选中颜色显示。跨换行选择时，换行处显示一个选中空格，其余补位空白保持原样；窄屏滚动后只高亮当前可见的选区。大段粘贴原本折叠为摘要时，开始选择会先展开原文，避免摘要位置与真实文字范围混用。

- 输入文字、粘贴文本、换行或 Alt-Y 粘回剪切内容，会替换选区。空粘贴不删除选区。
- Backspace、Delete、Ctrl-H 先删除选区；按词删除和 Ctrl-K 对选区执行原有剪切操作。
- 普通左右方向键分别收起到选区起点、终点；其他普通移动结束选择。普通鼠标点击也会结束选择，即使点击位置与当前光标相同。开始正文选区时会结束附件选择；成功加入图片附件并选中时则结束正文选区，使删除对象与高亮一致；剪贴板图片和图片路径使用同一规则，图片被拒绝时保留原稿、光标和选区。
- Enter 仍提交完整输入，运行中仍按原规则排队；被当前输入校验拒绝时保留原文、光标和选区。成功提交后清空选区。应用层异步受理拒绝时，私有快照按精确 action、原会话及现有运行标记恢复原文、光标、选区、粘贴摘要和附件；晚到拒绝不覆盖已经输入的新草稿。
- 编辑队列中的跟进消息后，取消或保存会恢复原草稿及其选区；F3 设置的取消或保存也保留草稿、光标和选区。

## 粘贴目标

粘贴只交给当前可编辑表面。文本弹层、设置字段和打开的回答表单沿用各自的编辑规则；回答表单中的计划修改编辑器仍接受多行文本。只读 Plan Review 打开时，文本和图片路径粘贴不会穿透到背后的普通草稿，不改变草稿文字、选区、撤销历史、折叠粘贴信息或附件。按 Esc 关闭审查后，普通输入框才重新接收粘贴；已打开的回答表单仍优先拥有输入。

## 撤销与重做

Ctrl-Z 撤销输入、粘贴、删除、换行、剪切或 slash 补全，也能恢复 Esc 清空的草稿。Ctrl-Y 或 Ctrl-Shift-Z 重做；终端未发送 Shift-Ctrl-Z 时可以使用 Ctrl-Y。有重做记录时 Ctrl-Y 优先重做；没有重做记录时继续保持原有的粘回剪切内容行为。Alt-Y 始终粘回剪切内容，Ctrl-K 仍剪切到行尾。

每次编辑保留编辑前的文本、字素边界光标、选区及大段粘贴折叠信息，撤销选区替换可以恢复原选区。光标移动、焦点变化和无效删除不增加编辑记录。撤销后输入新内容会清除重做分支。编辑历史最多保留 100 步及 4 MiB 的文本与粘贴元数据；超出预算会丢弃最旧记录，超过单次预算的大草稿不保留为重做副本。

成功发送或真正切换会话后清除当前编辑历史。运行提交在异步受理前被拒绝时，按原有精确身份保护恢复编辑上下文；晚到拒绝不能覆盖新草稿。队列编辑与普通输入各自保有编辑上下文，退出队列编辑后恢复原草稿、撤销/重做、剪切缓存及历史导航状态。浏览历史输入不会把其他提示词混进当前草稿的撤销链，返回新草稿后恢复原来的编辑历史。这些状态仅存在 TUI 进程内，不写入持久会话，也不能撤销已发送消息或工具效果。

Ctrl-A/E 继续表示行首、行尾，没有新增全选或系统剪贴板快捷键。鼠标拖选输入框不属于本批范围。快捷键需要终端实际发送对应按键事件；macOS Terminal 的修饰键、正向 Delete 与输入法行为需分别实机验证，不能从单元测试推断已通过。

## 文本弹层与退出保护

模型 ID、API 地址等普通文本弹层沿用字素边界移动：左右、Home/End、Ctrl-A/E 与 Shift 选择，
输入或粘贴替换选区，Backspace/Delete 删除，Ctrl-U 清空。Ctrl-Z 撤销，Ctrl-Y 或 Ctrl-Shift-Z 重做；
记录有界且只在弹层内保留，不混入背后草稿。密钥输入保持遮罩，不创建普通文本撤销副本。
长值随真实光标滚动，关闭或取消弹层不把内容写入背后的输入框。普通 composer 的 Ctrl-U 仍是阅读滚动。

空闲时使用 Ctrl-C 或退出命令，有未发送文字、附件或未保存设置会先询问。Enter、Esc 或再次 Ctrl-C 继续编辑，
保留原草稿与编辑上下文；Ctrl-D 明确放弃并退出。运行中 Ctrl-C 仍请求取消，已选会话文字仍先按原规则复制。
保护只发生在正常退出路径，不新增磁盘草稿存储，也不能恢复明确放弃的内容。

## 验证边界

本实现仅修改内部 `sigil-tui-host` 的输入状态、渲染和用户提示；不修改共享运行语义、审批身份、队列 CAS 或持久会话格式。输入框折行结果保留原始字符范围，与光标使用相同的终端列宽规则；恰好到达右边界后紧接硬换行时只前进一行，避免重复空行。末尾的虚拟光标行由原有视口补位处理。选区不会误染宽字符之前的空白，也不会把已裁切行重新从零计数。

定向回归覆盖原生复现对应的 `甲乙🙂丙` 选中表情后粘贴替换、反向收缩、组合字素与 ZWJ、跨行和软换行、删除/换行/粘回、空粘贴与折叠大粘贴、提交与队列编辑、异步受理拒绝及晚到/跨会话保护、设置往返、鼠标点击，以及 80×24 的实际渲染缓冲区。实机资格由独立不可变构建后的走查结果给出。
