# TUI 工作区信任页

TUI 第一次进入未信任工作区时，用一个页面询问“Trust this workspace?”。页面只呈现工作区路径、信任的影响和继续／退出操作，不再重复显示状态栏、配置文件名和多个工作区信任标题。

- 信任会允许加载仓库内指令、检查并进入正常 agent 执行。未信任仓库保持 data-only，不能启动正常 agent 执行。工具权限和审批规则不因这次页面调整而改变。
- `Enter`（兼容 `Y`）明确确认并继续；`Esc` 或 `Ctrl-C` 退出。确认沿既有共享信任契约追加持久决定，退出不会写入信任决定。
- 问题、影响说明和操作提示在 80×12 中同时可见。路径占用独立的换行区域，较长时显示行范围；`↑/↓`、`PgUp/PgDn`、`Home/End` 只滚动路径，不会确认或修改信任。
- 80×24 和 140×44 使用同一个页面结构；调整尺寸只重新计算展示范围，不扩大授权。

实现位于内部 `sigil-tui-host` 的 workspace-trust 状态、surface 投影和专用 renderer，不改变公共 framework、provider、Desktop 或 session 的信任授权语义。
