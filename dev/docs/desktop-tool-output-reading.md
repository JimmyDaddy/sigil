# Desktop 工具输出阅读

日期：2026-10-23。本文约束工具卡片中预览、完整输出与搜索的信息层级；实现位于
[`ToolCard.tsx`](../../apps/desktop/src/ToolCard.tsx)。真实界面验收继续遵守
[产品体验基线](product-experience-acceptance.md)，组件测试不能替代原生窗口复验。

## 设计依据与取舍

- [Apple HIG：Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)
  建议常用操作保持可见，低频细节按需披露，展开控件紧邻相关内容。因此移除“完整输出与搜索”
  外层大折叠框，直接用一次“查看完整输出”操作进入正文，不再先展开一层菜单。
- [Carbon：Code snippet](https://www.carbondesignsystem.com/building-blocks/core/components/code-snippet/guidelines)
  把文本作为核心，展开/收起作为简短的辅助操作。工具输出采用同一阅读位置，预览与已读正文不重复堆叠；
  从头查看和分页保持次级视觉，不再使用多个大标题和嵌套描边。
- [WCAG：Focus Visible](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible.html)
  要求键盘用户能识别当前焦点。紧凑按钮及正文滚动区保留 `:focus-visible`，焦点描边只包围实际控件，
  不通过移除焦点提示来减轻视觉噪音。完整可访问性资格化仍需真实键盘、缩放和平台验证。

这里借鉴信息层级与交互原则，不复制其他产品的组件，也不改变 Sigil 的读取权限与预算。

## 默认与展开状态

| 状态 | 展示与操作 |
| --- | --- |
| 长输出默认状态 | 简短预览；工具栏只有“查看完整输出”和搜索图标。查看一次即发起有界读取，不增加前置折叠步骤 |
| 完整正文 | 同一位置显示当前页；工具栏可收起、从头查看或打开搜索。范围、分页和末尾提示低于正文层级 |
| 收起后重开 | 恢复本卡片当前已读页、滚动位置和分页历史，不重新读取，也不消耗额外预算 |
| 完整短输出 | 保留自动有界读取与正文直显，只留下次要搜索入口；失败、非完整页或二进制仍有重试/从头查看 |
| 搜索 | 图标具有可访问名称与提示；输入框默认隐藏，打开后获得焦点。Escape 只收起输入框，返回图标，保留查询和结果 |
| 搜索结果 | 已提交查询、扫描范围、命中数、零命中及结束信息与正文一起可见。未提交的新文本不修改当前结果标签 |
| 返回正文 | 恢复搜索前的实际正文页和滚动/焦点；从预览直接搜索时返回原预览，并将焦点交还完整输出入口 |
| 读取失败 | 保留原有正文和导航，显示可理解的失败提示；不把失败伪装成空正文或成功结果 |

工具栏可以换行；输入区使用可收缩宽度，正文长行可换行，避免窄窗口中控件或输出撑破卡片。
正文继续使用安全代码展示组件，不把输出作为 HTML 执行。默认预览在完整读取可用时不另提供一个容易与
“查看完整输出”混淆的本地展开入口；没有可读取 artifact 时，原有输出展开行为继续可用。

## 状态与权限边界

- 展开/收起只改变 renderer 本地阅读状态；不取消后台运行、不重新执行工具、不改变 session truth。
- 使用现有 typed `ToolArtifactSelector`、`ToolArtifactPage`、`nextSelector`、`eof` 和 `returnedBytes`。
  不新增 Rust command、IPC capability、renderer 路径、凭证或通用文件访问。
- 保留每卡片最多 8 页且正文 UTF-8 总量最多 64 KiB 的本地缓存。缓存 key 使用归一化 typed selector，
  不是输入框中未提交的查询；上一页和下一页命中已读缓存时不再调用读取接口。
- 明确点击“从头查看”仍调用既有有界读取路径，不借缓存跳过该动作；读取额度由既有后端执行。
- tool key、artifact identity 或可用性变化时清除本卡片的正文、分页、查询与缓存；过时异步结果不能覆盖新对象。
- 搜索返回位置独立于搜索分页，失败不覆盖当前页。布局变化不得丢失阅读位置或重复请求。

## 验证范围

定向组件回归覆盖单次进入、收起重开不重复读取、分页缓存、缓存淘汰、搜索默认隐藏/Escape、查询保留、
零命中、返回原页与焦点、读取失败及 identity 变化。调用层保留 typed selector 与不可用 artifact 的原有断言。

原生复验分别记录普通/紧凑窗口和键盘操作：确认没有大号嵌套框、整行焦点抢占、重复正文或二次进入步骤，
并核对收起重开、搜索返回与分页可达。通过情况及构建身份写入当前体验报告；本文不预先宣称原生验收通过。
