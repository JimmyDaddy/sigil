# TUI 设置页展示

设置页将日常操作需要的信息集中在标题、当前栏目和底部动作中。

- 页首显示 `Settings`，并只显示一次 `saved`、`unsaved` 或 `save failed` 保存状态。当前栏目与字段继续在正文中标明，不再在顶部重复 `section:`、`field:` 和已保存说明。
- 默认配置文件名 `sigil.toml` 不常驻占一行。使用自定义配置文件名时，在第二行用安静的 `Config:` 文件标签替代普通导航提示，并按可见宽度截断，帮助区分正在编辑的配置；它仍是受限展示标签，不暴露 authority 路径。
- 普通页首提示栏目切换、字段移动和编辑方式。底部原有按钮直接标明 `Ctrl-S save`、`F3 save+close`、`Esc close`，不再重复一排相同动作或保存状态。其他栏目已有的额外动作保持原语义。
- 有未保存修改时，`unsaved` 仍醒目显示。关闭确认替换普通导航提示，完整说明再次 Esc 会丢弃修改。实际保存失败、字段校验错误及恢复指引继续显示；保存失败页脚仍可显示具体错误。

本次只调整设置渲染和已有按钮的文字，未改变设置流、保存与激活语义、权限、持久化或主题体系。正文内容与滚动标记保留，页首高度、面板与页脚布局规则不变。按钮渲染和鼠标命中矩形继续共用同一个文字测宽函数，键位标签不会落在不可点击区域。

验证复用现有设置页测试，重点检查 80×24 的实际生产 surface、唯一保存状态、当前栏目与字段、完整关闭确认、真实保存失败、自定义文件名和主题颜色，以及 80/160 列下按钮文字与命中区边界。实机体验以本批独立构建为准，不借用前一批原生截图作为本批资格。
