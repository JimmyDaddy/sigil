# TUI 操作反馈与工具输出阅读

TUI 主界面保留单行底栏。没有可聚焦的工具活动、读取受限或失败、以及复制结果等需要反馈的操作，会暂时在原底栏显示一句提示，并保留 `F1` 帮助；下一次按键恢复当前焦点的快捷键。普通焦点切换、运行阶段和状态摘要不额外占用主画面行数。输入焦点优先显示发送、换行和帮助；工具焦点显示工具展开、搜索、回到输入，运行期间保留取消入口。

工具全文仍通过已有的 typed artifact page 读取，不改变权限、审计或每会话读取预算。阅读区持续显示正文行/字节范围，或搜索 literal、当前页命中数与搜索起点；到达末尾单独标记。没有搜索命中与空正文使用不同提示。读取后仅保留一个主要正文区，不继续复用原始工具预览中的行号或结构化布局来解释新的页内容。

- `Ctrl-G` 聚焦最近工具活动，`Ctrl-O` 展开或收起预览。
- `Alt-N` 读取下一页；如果下一页已经读过，直接显示缓存，不再发请求。
- `Alt-F` 搜索 literal，再次打开时保留最近成功搜索的查询；在搜索输入框按 `Ctrl-U` 清空当前查询，便于直接输入新的查询。
- `Alt-Left` 按实际浏览顺序返回此前页面，正文页与搜索页的缓存插入顺序不影响返回目标；最初页面之前返回原始预览。
- `Alt-Home` 从搜索返回搜索前正在显示的正文页，包括先返回旧页再发起搜索的情况；正文页再按则返回原始预览。搜索前显示的是原始预览时，直接回原始预览。
- `Esc` 返回输入；`F1` 查看全部按键。输入框已有草稿时，`Alt-Left` 等编辑键继续由输入框处理。

缓存与浏览历史只属于当前 TUI 会话的展示状态。缓存最多保留 8 页，原始卡片与页正文合计不超过 512 KiB；每张卡片另外最多保留 8 步浏览历史，历史只引用已读页并保存当时的正文位置，不复制页正文。超限会淘汰旧缓存及对应历史。新读取、返回缓存页和重新聚焦已读输出时，都从该页页首显示标题与范围，不承诺恢复页内滚动位置。已读取的页完整参与主时间线滚动，不再被普通工具预览的 64 行分段上限截断；正文与搜索结果只显示当前阅读页的范围或命中信息，不沿用原始预览的行数摘要。该导航不产生新读取，也不扩大读取预算。切换会话、输出失效或权限被撤销会清理相应缓存；未缓存的内容仍需通过原读取路径取得，预算不足或不可用时明确反馈原因；预算拒绝保留已读页和返回/前进缓存，只有实际权限撤销才按撤权清理。
