# TUI 键盘帮助

F1 默认打开 Common，优先显示输入、浏览与控制的常用操作。Tab 或 Shift+Tab 切换到 All shortcuts，保留原有完整键位和 slash command 目录；这两种切换只作用于帮助，不改变权限模式或执行下层命令。

标题、页签和操作提示固定，正文独立滚动。Up/Down 按终端视觉行滚动，PageUp/PageDown 按可见正文翻页，Home/End 到页首/页尾。宽字符与长行先使用现有终端折行函数转换为实际行，绘制和滚动边界复用同一结果；窗口尺寸变化后有效偏移重新受限。

Esc/Enter 只关闭帮助，保留草稿、输入光标和底层会话滚动位置。Ctrl-C 的原有强控制语义保持不变：有选择时优先复制，运行时请求取消，空闲时退出；已有受控写操作的退出保护保持不变。帮助不会创建新的审批、命令别名或权限。

80×24 和 144×44 的生产 Surface 渲染回归覆盖首屏优先级、完整目录尾部可达、固定页签/页脚和视觉行边界；局部键处理回归覆盖草稿保留、忙碌时关闭帮助和 Ctrl-C 原语义。最终原生候选的实际 F1 首屏/翻页由产品体验另行确认，组件测试不作为原生体验通过证据。
