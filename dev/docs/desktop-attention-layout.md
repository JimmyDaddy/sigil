# 桌面提问与同步状态的呈现

等待回答时，以当前问题为主；普通对话记录默认收起，可通过“查看对话”展开。原 timeline 和消息草稿保持挂载，保留阅读位置、原文、预览和附件。加载失败或历史契约错误时自动展开对话，保留错误说明与重试入口。

消息草稿默认保持可编辑，由用户手动收起；新问题不会异步隐藏正在编辑的内容。手动收起会关闭该草稿的格式、上下文、队列浮层；展开后继续编辑同一原文。短窗口给问题独立滚动空间，动作区可以完整滚到，外层保留必要的溢出滚动。

正常 checking_owner、attaching_run、finalizing 使用一处紧凑状态反馈。发送是否可用仍由原有连续性与运行 guard 决定；只有 typed 只读恢复或契约错误才在草稿提示恢复运行控制。真实恢复警告、路由修复和重试动作保持可见。

实机复验记录与构建身份见 `.repo-local-dev/review/product-experience-20261023.md`；脚本 provider 的原生体验验证与真实模型质量分开记录。
