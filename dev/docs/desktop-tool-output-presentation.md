# Desktop 工具输出与搜索

工具输出以正文为主，补充动作按需要展开。已保存输出不超过4096字节时，沿用现有自动读取；只有本次工具的完整 UTF-8 首页面已成功返回、返回字节数与持久正文相符、没有下一页，且工具状态成功、没有更多输出标记时，才以轻量的“搜索工具输出”次要入口替代带外框的“完整输出与搜索”。全文已经显示时不再重复提供“从头查看”按钮。

搜索仍使用同一个工具附件的受限字面搜索。完整原文保持可见，搜索结果在展开区单独显示，后续搜索与结果翻页不会覆盖原文。搜索失败保留原文、查询与重试入口；初次读取失败仍保留完整查看与重试能力。工具或附件身份切换时，清除旧正文缓存、查询和结果，晚到的旧读取不能进入新工具卡。

长输出、未读完的页面、更多输出标记、工具失败和二进制输出保留原有完整输出、搜索与分页入口。原有字节读取上限、附件权限、引用身份、状态和审计事实不变；这项呈现调整不合并工具调用、不解释取消正文，也不隐藏等待输入的历史记录。

组件回归覆盖短 Unicode 原文及独立搜索分页、失败重试、二进制/分页边界和工具/附件切换后的晚到结果。原生字号、留白与控件可达性仍由最终候选的实机走查确认。
