# Desktop 输入与排队正文约定

主输入区以 Markdown 原文作为发送与草稿正文，安全预览只派生显示。实时预览的完整文档沿用现有 fence 修复和 SafeMarkdown 渲染，不先构建只供流式使用的分块投影；完整正文不会因此截断。流式消息仍使用原有稳定前缀投影，HTML、链接、数学与 Mermaid 的安全边界不变。

建议打开时，Tab 或不带 Shift 的 Enter 选择建议；Shift+Tab 始终保留向前一个控件移焦的行为，不执行建议中的命令。组合输入 guard 仍先于建议与发送，主输入的 Enter 发送、Shift+Enter 换行约定不变。

排队消息的替换只用 trim 判断是否为空，实际提交用户输入的原始字符串，保留 Markdown 首行缩进、首尾换行和行末空格。完整安全正文可以预填；脱敏、截断或仅进程内材料仍要求用户完整重新输入，不拿预览补造原文。保存失败继续保留正在编辑的文本。

组件回归分别覆盖反向焦点、正常 Tab、精确排队替换与空白拒绝、完整 Markdown 的有界整串编码次数、CRLF/fence/code 呈现与流式转换。原生输入法、WebKit 焦点与窗口几何仍由最终候选实机确认。
