# 功能可用性与故障隔离

本文记录普通功能的准入边界。辅助状态失败应保留独立可用的操作；真实身份、权限、资源容量与目标冲突继续在执行边界校验。

## Desktop 恢复期间的停止与暂停

实时订阅中断或展示连续性恢复时，已绑定当前 session/run 的停止与任务暂停仍可使用。native 继续读取当前运行状态，服务端校验身份与控制序列；控制请求进行中、运行身份不匹配或已终结时不开放重复操作。恢复状态仍约束依赖完整上下文的新提交。

## 无会话时修复默认模型

设置页不依赖会话即可修改已有连接的默认模型：从实际配置的连接列表选择连接，填写 model ID，再保存默认 route。已有上下文时继续使用模型选择器。保存成功后，新会话采用已保存的 route；缺凭证或连接配置非法仍由该 route 的真实运行条件报告。

## 更新查询与缓存

在线查询成功后，即使本地缓存无法持久化也返回实际查询结果并记录诊断；用户可继续使用已验证的更新候选。缓存重复写入相同内容是幂等成功。下载、发行验证及安装边界保持独立，缓存成功不代表安装成功。
