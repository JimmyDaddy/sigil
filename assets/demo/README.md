# Sigil public demos

This directory contains the public Desktop and TUI demos.

## Desktop

The Desktop tour is a short, silent walkthrough built from real application
captures. It replaces an unusable long source recording whose frames were
mostly black; raw recording diagnostics stay local and are not published.

- `sigil-desktop-demo.mp4`: H.264, 1440 × 900, 17 seconds.
- `sigil-desktop-demo.webm`: VP9 fallback for the website.
- `sigil-desktop-demo-poster.png`: real Desktop workbench capture.
- `sigil-desktop-demo.en.vtt`: English description track.
- `sigil-desktop-demo.zh-CN.vtt`: Simplified Chinese description track.

## TUI

The TUI launch demo was built from a real Sigil run in a disposable
repository.

- `sigil-45-second-demo.mp4`: H.264, 1920 × 1080, 30 fps.
- `sigil-45-second-demo.webm`: VP9 fallback for the website.
- `sigil-45-second-demo-poster.png`: approval-review poster frame.
- `sigil-45-second-demo.en.vtt`: English captions.
- `sigil-45-second-demo.zh-CN.vtt`: Simplified Chinese captions.
- `sigil-45-second-demo-end-card.svg`: editable branded end-card source.

The canonical prompt, recording constraints, timing, and acceptance checklist
live in [`dev/docs/launch/45-second-demo-script.md`](../../dev/docs/launch/45-second-demo-script.md).
Raw recordings remain local and are not published.

The original launch video remains the focused edit, approval, verification, and
resume demo. The separate real-run script for AI-generated plans, parallel Task
steps, and final verification lives in
[`dev/docs/launch/ai-planned-task-demo-script.md`](../../dev/docs/launch/ai-planned-task-demo-script.md).
